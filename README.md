# 2~4인 온라인 루미큐브

2~4명이 방 코드로 실시간 플레이하거나 사람과 AI를 섞어 플레이할 수 있는 웹 게임입니다. 외부 패키지 없이 Node.js 18 이상만 사용합니다.

## 실행

```bash
npm start
```

브라우저에서 `http://localhost:3000`으로 접속합니다. Render에 배포하면 PC 없이 스마트폰/태블릿에서도 사용할 수 있습니다.

## 방 만들기

- 최대 참가 인원: 2명 / 3명 / 4명
- AI 참가자 수: 0명부터 최대 인원-1명까지
- 한 턴 제한 시간 설정
- 방장은 대기실에서 참가자 구성을 확인한 뒤 `게임 시작`을 누릅니다.
- 설정한 사람 참가자 수가 모두 들어와야 게임을 시작할 수 있습니다.
- 예: 사람 2명 + AI 2명, 사람 3명 + AI 1명, 사람 4명 등

## 주요 규칙/기능

- 숫자 1~13, 4색, 각 2세트 + 조커 2장 (총 106장)
- 각 플레이어 14장 시작
- 첫 등록은 자기 패만 사용해 합계 30점 이상
- 첫 등록 후 공용 테이블 재배치 가능
- 서버에서 모든 묶음의 유효성 검사
- 2~4명 순환 턴, 서버 기준 턴 타이머
- AI는 기본 수준으로 첫 등록, 기존 묶음 확장, 새 묶음 생성을 시도
- 직전 플레이어가 재배치한 타일/새로 낸 타일 강조
- 턴 전환 효과음
- 직전 한 수 Undo / 이번 턴 전체 되돌리기
- 공용 테이블 각 묶음 자동 숫자 정렬
- 새 게임 설정에서 사람 참가자 수, AI 수, 턴 제한 시간을 다시 지정하고 대기실로 복귀
- 사람 수를 줄이면 방장을 남기고 나중에 들어온 참가자부터 방에서 제외
- `지금 게임 중지`/`세션 종료`로 방 세션을 서버에서 완전히 삭제
- iPad, Galaxy Tab, Surface, 스마트폰, PC에서 Pointer Events 기반 드래그 지원
- 첫 등록 전에도 이번 턴에 내 패에서 만든 새 묶음의 타일은 다른 새 묶음으로 다시 이동 가능
- PWA 설치 및 Render 배포 지원

## 한계

- 방/게임 상태는 서버 메모리에만 저장되어 서버 재시작 시 사라집니다.
- 로그인, 채팅, 관전자 기능은 없습니다.
- 조커 회수의 세부 공식 규칙은 별도 구현하지 않았습니다.
